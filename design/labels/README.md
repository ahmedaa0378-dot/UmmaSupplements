# Proposed front labels (not adopted)

A label redesign proposed in November 2026 in the bottle-and-brass direction. The decision was to keep the original pack artwork, so these files are kept for reference only and are not used on the site.

Re-render with `python3 make_labels.py` (needs Playwright, Chrome and the @fontsource packages for Cormorant Garamond, Hanken Grotesk and Amiri).
